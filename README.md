# 我的旅游攻略 Skill

根据目的地、日期、人数和预算生成中文慢旅行攻略 HTML。页面结构和排版固定，可选择封面主题色；“行程总览”右侧可以将整份攻略导出为 PNG 长图。

## 安装

在支持 `SKILL.md` 的 AI 工具中添加本仓库，或将本仓库完整复制到个人 Skills 目录。请保留 `assets/template-reference.html`，生成攻略时会以它为版式参考。

## 使用示例

```text
请用 my-travel-guide 制作慢旅行攻略。
目的地：杭州及周边
日期：2026.10.1—10.6
人数：2 人
出发地：沈阳
返程地：沈阳
住宿：1 间房，舒服安全
交通：高铁优先
节奏：慢游
人均预算：5000 元，包含往返大交通
封面配色：蓝色
```

必填信息和详细规则见 [SKILL.md](SKILL.md)。Skill 会先核实交通、预约、天气和费用；未来可能变化的信息会标注“出发前确认”。

## 长图导出

生成的 HTML 可在本地打开。点击“01 行程总览”右侧的“生成长图”，下载包含封面、全部章节和参考来源的 PNG。模板内置截图脚本，不依赖外部 CDN。若页面内容很长，导出仍可能受浏览器画布尺寸和设备内存限制。

## 文件

- `SKILL.md`：规划、核实与固定版式规则
- `assets/template-reference.html`：含导出按钮的自包含版式示例
- `assets/icon.svg`、`agents/openai.yaml`：Skill 展示信息
